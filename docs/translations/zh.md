# Simplified Chinese (zh) glossary

Language: 中文（简体）, zh-CN conventions. Register: informal-neutral, mostly without pronouns; when one is needed it is
你 (never 您). Full-width punctuation (，。：；？！), quotes “ ”. Buttons are bare verbs, tooltips follow the English
sentence. A space separates Chinese from Latin words (`创建 PR`), not from digits or `{{numeric placeholders}}`
(`{{count}}分钟前`); names and free text placeholders keep a space (`撤销 {{name}}`).

Kept in English (Latin letters, as Chinese developers say them): ticket, lane, PR, preview, job, commit, branch,
merge (as a noun/in "merge after"; the verb in lists is 合并), rebase, worktree, workspace, checkout, token,
passkey, webhook, CLI, skill, MCP, tailnet, Funnel, prompt, origin, SHA, git, backlog, spec/builder/runner/env/verify/
hunt/refute/intent (agent names), the default phase names (Implementation, Pushed, PR, CI, Preview, Summary, Merged).

Plural forms: only `_other` (zh has no plural categories); the `_one` keys are dropped.

Unsure: "运行项" for the board's Runs (preview/job definitions); "班次" for the report shift; the stall wording
("失联" for Lost contact, "停滞" for Stalled); palette keywords mix Chinese and English words on purpose so both
searches work. Phase names ticked by the board (Pushed, PR, CI...) stay English because the board creates them in English.
