# Português (pt-BR): glossário

Português do Brasil, legível também em Portugal. Registro: "você" implícito, informal e direto como as
ferramentas de desenvolvimento brasileiras: botões no infinitivo ("Salvar", "Gerar comandos"), dicas e instruções
no imperativo ("Pare o preview", "Clique para editar"). Sentence case como o inglês.

Mantidos em inglês, como os devs brasileiros falam: **ticket**, **lane**, **PR**, **preview**, **commit**,
**branch**, **worktree**, **workspace**, **checkout**, **token**, **webhook**, **CLI**, **skill**, **passkey**,
**tailnet**, **Funnel**, **prompt**, **merge** (substantivo; o verbo é "mesclar"), **push** (substantivo; o verbo é
"enviar"), **backlog**, **Roadmap**, **heartbeat**, **span**, **lease**, **job**, **builder/spec/runner**.

Plurais: `_one` + `_other` (o `one` do português cobre 0 e 1; `many` para milhões não é necessário).

Incertezas: "mesclar" para merge (alguns devs dizem "fazer merge"; os rótulos usam "mesclado"/"mesclar" e o
substantivo "merge"); "executor" para worker; "Pendentes de antes" para "Carrying over"; "Diário" para "Daily".
