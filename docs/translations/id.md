# Indonesian (id) glossary

Standard Indonesian (baku) in the informal-polite register of developer tools: "Anda" only where the sentence
needs a person, imperative for buttons and tips ("Simpan", "Buka", "Pasang"). Sentence case. Plurals: only
`_other` (no singular/plural split); counts use the bare noun with `{{count}}` ("{{count}} tiket").

Kept in English (Latin letters, as Indonesian developers say them): tiket (the one adapted spelling), lane, PR /
pull request, preview, commit, branch, merge, rebase, push, fetch, build, worktree, workspace, checkout, token,
webhook, CLI, skill, passkey, tailnet, Funnel, prompt, backlog, Roadmap, heartbeat, job, lease, span, spec,
builder, runner, maker. Verbs take the English stem with "di-" ("di-merge", "di-push", "di-rebase").

Unsure: "Pushed today" as "Di-push hari ini"; "Lost contact" as "Kontak hilang"; "Quiet" as "Senyap";
"carrying over" as "Terbawa"; the tech terms lease/span/heartbeat are left untranslated in the stalled-ticket text.
Command-palette keywords carry both Indonesian and the English words so either search finds the entry.
Values identical to English (65) are all legitimate: kept terms, brand, code, symbols, or pure placeholders.
