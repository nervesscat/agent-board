# Italian (it) glossary

Register: informal "tu". Buttons, menu items and tooltips are imperative ("Salva", "Annulla", "Elimina", "Ferma la
preview"); sentences address the reader with "tu" (or are impersonal). Quotes: “…”. Times without "a/alle" prefixes
where the value is `{{time}}` only after "alle"/"dalle" (hours are always singular-safe).

Kept in English (Latin letters, invariable in the plural: "le PR", "i ticket", "le preview"): ticket, lane, PR,
preview, commit, branch, worktree, workspace, checkout, token, webhook, CLI, skill, passkey, tailnet, Funnel, prompt,
repository, report, worker, backlog, job, build, lock, heartbeat, span, Roadmap, Team, merge (noun), push (noun and
"pushato / da pushare").

Plural forms: `_one` and `_other` (Intl also lists `many` for millions only; not needed).

Unsure: "Reach" column header in Cleanup ("Stato"); "Giornaliero" for the Daily page; "stage" as "colonna" in
sentences about a ticket's stage; "Implementazione" in the example phase list (the real default phase names come from
the project, not from this file); "stale/quiet" worker states as "Inattivo".
