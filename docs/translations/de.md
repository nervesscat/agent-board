# Deutsch (de)

Register: informal „du“, never mixed with „Sie“. Buttons and tooltips use the imperative or a short verb
phrase („Speichern“, „Agent verbinden“, „Hier ablegen“). Quotes are „ “. Short nouns and verbs on purpose:
German compounds are long and the top bar, tabs, buttons and the 390 px phone layout are tight.

Plural forms: `_one` + `_other` (as `Intl.PluralRules('de')`).

Kept in English (as German developers say them): Ticket, Lane, PR / Pull Request, Preview, Commit, Branch,
Worktree, Workspace, Checkout, Token, Webhook, Passkey, Skill, CLI, Tailnet, Funnel, Review, Run, Build, Job,
Push (verb: „pushen“, „gepusht“), merge (verb: „mergen“, „gemergt“), rebased, Daily, Roadmap, Team, Prompt.
