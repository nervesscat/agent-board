# Vietnamese (vi) glossary

Register: neutral and direct. Buttons are bare imperatives with no pronoun ("Lưu", "Xóa"); "bạn" only where a
sentence needs one. NFC diacritics. Plurals: only `_other` (`Intl.PluralRules('vi')` gives `other` alone).

Kept in English (Latin letters, never inflected): ticket, lane, PR, preview, commit, branch, merge, rebase, push,
fetch, origin, worktree, workspace, checkout, token, webhook, passkey, tailnet, Funnel, CLI, skill, prompt, build,
job, tag, repo, agent, subagent, orchestrator, worker, builder/spec/runner/maker/intent, lease, heartbeat, span,
backlog, review, CI, MCP, SHA, Board.

| English                      | Vietnamese                      |
| ---------------------------- | ------------------------------- |
| project / stage / phase      | dự án / cột / giai đoạn         |
| task / subtask / run         | tác vụ / tác vụ con / lượt chạy |
| summary / report / Daily     | tóm tắt / báo cáo / Hằng ngày   |
| Settings / device            | Cài đặt / thiết bị              |
| sign in / sign out           | đăng nhập / đăng xuất           |
| attachment / notification    | tệp đính kèm / thông báo        |
| search / save / cancel       | tìm kiếm / lưu / hủy            |
| delete / remove / keep       | xóa / gỡ / giữ                  |
| Needs you                    | Cần bạn                         |
| in progress / blocked / done | đang làm / bị chặn / xong       |
| on hold / assignee           | tạm giữ / người được giao       |
| this machine                 | máy này                         |
| Overview / Roadmap / Cleanup | Tổng quan / Lộ trình / Dọn dẹp  |
| Team / Gallery               | Nhóm / Thư viện                 |
| approve / disapprove         | duyệt / không duyệt             |
| revoke                       | thu hồi                         |
| comment / reply / post       | bình luận / phản hồi / bài đăng |

Unsure: "stage" is "cột" and "phase" "giai đoạn" to keep them apart; "No word" is "Không tin tức"; compact time
units are `ph`, `g`, `ng`; palette `keywords` mix Vietnamese with the English words developers type.
