# Korean (ko) glossary

Register: 해요체 for sentences (with the period, like the English), noun-final labels for titles, tabs, buttons and
menu items ("저장", "삭제", "닫기"), noun phrases for tooltips where short. The user is addressed with "당신" only where
the English says "you" about the human (rare); otherwise the subject is left out.

Particles (은/는, 이/가, 을/를, 으로/로) are never placed right after a `{{placeholder}}`, whose last sound is unknown.
The sentence is restructured instead: a noun follows the placeholder ("{{name}} 단계를 삭제할까요?"), a colon is used
("중지됨: {{reason}}"), or only sound-independent particles follow (에, 에서, 에게, 까지, 부터, 의, 도, 만).

Plural forms: Korean has only `other`; every `_one` key of the English became just `x_other`, and counts are written
with counters (개, 건, 명, 줄, 분, 시간).

Kept in Latin letters: brand CrossBoard, Tailscale, Funnel, HTTPS, git, gh, claude, SHA, origin, CI, MCP, CLI, PR, QA,
KB, and the names of the review agents (spec, builder, runner, env, verify, hunt, refute, merge, intent).

Unsure about: "선행 필요 / 선행 대상" for the ticket dependency (needs / needed by); "연락 끊김" for "Lost contact";
"일일" as the page name for Daily; the palette search keywords are Korean with a few English words kept (pr, mcp, url,
git) because developers search by them.
