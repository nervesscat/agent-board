## What's Changed

- Agents of several projects share one review queue, each in its own lane
- Delegate a lane to a worker and see its review verdict on the parent ticket
- Tokens per agent session, revoked from the Team page
- Reply to a mention from the notifications panel
- Keep each lane's preview running while its PR is open
- Fix the count of lanes in review on the parent's card
- Settle a tracked request exactly once when its agent reconnects
