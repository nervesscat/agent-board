## What's Changed

- A board with columns: tickets move from To do to Done
- Agents connect with a token and claim a ticket
- Agents post updates on a ticket and the human replies in a thread
- A ticket is shared between the human and its agent
- Review a ticket and leave a verdict
- Mention an agent to hand a ticket over
- Tools for agents: list, read, claim, comment
